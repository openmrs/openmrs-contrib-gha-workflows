Push translations

tx-push.yml uploads the repository’s source strings to Transifex so translators can work on them. It is usually run when the source strings change on the default branch; its counterpart, Pull translations, brings the translations back.

Usage

.github/workflows/tx-push.yml
on:
  push:
    branches: [main]
 
jobs:
  push-translations:
    if: github.repository_owner == 'openmrs'
    uses: openmrs/openmrs-contrib-gha-workflows/.github/workflows/tx-push.yml@main
    secrets:
      TRANSIFEX_TOKEN: ${{ secrets.TRANSIFEX_TOKEN }}

What it does

  1. Checks out the repository.
  2. Runs the Transifex CLI with transifex_args (by default push --source), using the repository’s .tx/config.

OpenMRS defaults

OpenMRS repositories pass the organization’s TRANSIFEX_TOKEN and use the default arguments.

Outside OpenMRS

The Transifex workflows are for repositories in the OpenMRS organization, which share its Transifex project. They are not supported for use elsewhere.

Permissions

The job requests actions: read only. Because it declares a permissions block, it does not get contents: read, so it can only check out public repositories.
